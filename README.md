# Jude Belarbino Fernandes — Portfolio

A one-page, video-led producer portfolio built with Vite, HTML, CSS, vanilla JavaScript, Lenis and GSAP.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

The production website is generated in `dist/`.

## Editing content

- Project cards and YouTube IDs are in `index.html`.
- Styling is in `css/style.css`.
- Interactions, Lenis, GSAP, filtering and video modal are in `js/main.js`.
- Replace the abstract hero artwork in `.hero-image-fallback` with Jude's approved portrait or showreel still when supplied.
- YouTube thumbnails are loaded from YouTube's image CDN. If a video does not expose a thumbnail at `hqdefault.jpg`, replace its image URL with an approved still.
- YouTube playback is embedded in a privacy-enhanced player.
